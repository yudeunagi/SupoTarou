# 画面色スポイトアプリ 仕様書

## 1. 概要

### 1.1 アプリケーション名称

仮称：

**スポ太郎**

※正式名称は別途決定する。

### 1.2 目的

Windows上に表示されている画面の任意の位置から色を取得し、取得した色をHSV形式およびグラフィカルなカラーピッカー形式で表示する。

マウスカーソルを画面上で移動することでリアルタイムに取得色を変更でき、**Spaceキーを押すことで現在の色を固定表示**する。

### 1.3 対象OS

- Windows 10
- Windows 11

※Windows 11を主要対象とする。

### 1.4 開発環境

| 項目 | 採用技術 |
|---|---|
| プログラミング言語 | C# |
| UIフレームワーク | WPF |
| プラットフォーム | .NET |
| 対象OS | Windows |
| 画面取得 | Windows API / .NET |
| 色表現 | RGB / HSV |

---

## 2. 基本コンセプト

アプリ起動後、マウスカーソルが存在する画面上の位置の色をリアルタイムに取得する。

取得した色をHSVへ変換し、以下の2種類の方法で表示する。

### 数値表示

```text
H : 58
S : 90
V : 100
```

### グラフィカル表示

- 外周のリング：H（色相）
- 内側の四角形：S（彩度）/ V（明度）
- マーカー：現在取得している色の位置

---

## 3. 機能一覧

| ID | 機能 | 概要 |
|---|---|---|
| F-01 | 色取得 | マウスカーソル位置の画面色を取得する |
| F-02 | HSV変換 | 取得したRGBをHSVへ変換する |
| F-03 | HSV数値表示 | H/S/Vを数値で表示する |
| F-04 | Hリング表示 | Hに対応する位置を色相リング上に表示する |
| F-05 | SV四角形表示 | S/Vを2次元領域として表示する |
| F-06 | 現在色カーソル表示 | SV領域上に現在色の位置を表示する |
| F-07 | リアルタイム更新 | マウス移動に応じて表示色を更新する |
| F-08 | 非アクティブ動作 | アプリが非アクティブでも色取得を継続する |
| F-09 | 色固定 | Spaceキーで現在色を固定する |
| F-10 | 固定解除 | 再度Spaceキーを押すことで固定を解除する |
| F-11 | 固定状態表示 | 現在の状態が「取得中」か「固定中」か判別できるようにする |

## 5. 色取得仕様

### 5.1 取得対象

色取得対象は、**マウスカーソルのホットスポット位置に存在する画面上のピクセル**とする。

マウスカーソル自体は取得対象に含めない。

### 5.2 色取得処理

1. マウスカーソルの画面座標を取得する。
2. カーソル座標に対応する画面上のピクセルを取得する。
3. 取得したRGB値をHSVへ変換する。
4. HSV数値およびグラフィカル表示を更新する。

---

## 6. HSV仕様

### 6.1 H（Hue）

色相を表す。

範囲：

```text
0 ～ 360°
```

代表的な色：

| H | 色 |
|---:|---|
| 0° | 赤 |
| 60° | 黄 |
| 120° | 緑 |
| 180° | シアン |
| 240° | 青 |
| 300° | マゼンタ |
| 360° | 赤 |

### 6.2 S（Saturation）

彩度を表す。

範囲：

```text
0 ～ 100%
```

### 6.3 V（Value）

明度を表す。

範囲：

```text
0 ～ 100%
```

---

## 7. Hリング仕様

### 7.1 概要

円形の色相リングを表示する。

リング上にはHSVにおける各色相を連続的に表示する。

**リングの最上部をH=60°（黄色）とする。**

色相は時計回りに変化する。

| 位置 | H |
|---|---:|
| 真上 | **60°（黄色）** |
| 右上 | 90°～120° |
| 右 | 150°～180° |
| 右下 | 210°～240° |
| 下 | 240°～300° |
| 左下 | 300°～330° |
| 左 | 0°～360°付近 |
| 左上 | 30°～60° |

※リングは360°で循環するため、H=0°とH=360°は同じ赤色を表す。

### 7.2 現在Hの表示

現在取得しているHの位置を、リング上にマーカーで表示する。

例えば取得した色が、

```text
H = 60°
S = 100%
V = 100%
```

の場合、Hリングの**真上**にマーカーを表示する。

### 7.3 Hリングの色

リング上の色は、

```text
HSV(H, 100%, 100%)
```

をRGBへ変換した色を使用する。

H=60°の位置は黄色となる。

### 7.4 Hの角度と画面上の位置

Hリングの角度は以下のルールで定義する。

- **H=60° → 真上**
- **H=150° → 右**
- **H=240° → 真下**
- **H=330° → 左**

画面上の角度を計算する際には、一般的な数学座標系の0°位置をそのままH=0°として扱わず、**H=60°が12時方向になるようにオフセットする**。

---

## 8. SV四角形仕様

### 8.1 概要

Hリングの内側に、現在のHに対応するS/V領域を表示する。

```text
       S →
    0          100
    ┌────────────┐
    │            │
 V  │            │
 ↓  │      ●     │
    │            │
    │            │
    └────────────┘
```

### 8.2 軸

横方向：

```text
S = 0% → 100%
```

縦方向：

```text
V = 100% → 0%
```

したがって、

- 左上 = S 0%, V 100%
- 右上 = S 100%, V 100%
- 左下 = S 0%, V 0%
- 右下 = S 100%, V 0%

となる。

### 8.3 Hとの関係

SV四角形ではHを固定する。

例えば現在のHが60°の場合、

```text
H = 60°
```

を固定し、

```text
S = 0～100%
V = 0～100%
```

を変化させて各位置の色を生成する。

---

## 9. HSVグラフィカル表示と取得色の同期

画面から色を取得した場合、以下の処理を行う。

```text
画面ピクセル
    ↓
RGB
    ↓
HSV変換
    ↓
H / S / V
    ↓
┌──────────────┐
│ Hリング更新   │
│ SV領域更新    │
│ Hマーカー更新 │
│ SVマーカー更新│
└──────────────┘
```

数値表示とグラフィカル表示は常に同一のHSV値を使用する。

---

## 10. リアルタイム色取得

### 10.1 基本動作

アプリが「取得中」状態の場合、マウスカーソル位置を監視する。

```text
マウス移動
   ↓
カーソル座標取得
   ↓
画面ピクセル取得
   ↓
RGB取得
   ↓
HSV変換
   ↓
画面表示更新
```

### 10.2 更新頻度

初期仕様では**30～60fps程度**を目標とする。

ただし、画面全体を毎フレームキャプチャする方式は避け、可能な限り必要なピクセルのみ取得する。

---

## 11. アプリ非アクティブ時の動作

### 11.1 要件

アプリ自身がフォーカスを持っていない状態でも、色取得を継続する。

例えば、別のアプリケーションがアクティブな状態でも、そのアプリ上のマウスカーソル位置の色を取得できること。

### 11.2 アプリウィンドウ上にカーソルがある場合

アプリ自身のウィンドウ上にカーソルがある場合も、基本的には通常通りカーソル位置の画面色を取得する。

初期仕様では、画面に実際に表示されているピクセルを取得対象とする。

---

## 12. Spaceキーによる色固定

### 12.1 通常状態

アプリ起動直後は、

```text
状態：取得中
```

とする。

マウスカーソルを移動すると色が変化する。

### 12.2 Spaceキー押下

Spaceキーを押した瞬間の色を固定する。

```text
現在

RGB : 128, 64, 32
HSV : 20°, 75%, 50%

        ↓ Space

固定

RGB : 128, 64, 32
HSV : 20°, 75%, 50%
```

その後マウスを移動しても表示色は変更しない。

---

## 13. 固定状態

固定中は、

```text
状態：固定中
```

と表示する。

Hリング、SV四角形、HSV数値は固定した色を表示する。

固定中にマウスを移動しても、表示色は変更しない。

---

## 14. 固定解除

固定中に再度Spaceキーを押すと、固定を解除する。

```text
固定中
   ↓
Space
   ↓
取得中
   ↓
現在のカーソル位置の色を取得
```

固定解除直後は、その時点のマウスカーソル位置の色を取得して表示する。

---

## 15. 非アクティブ時のSpaceキー

通常のWPFの`KeyDown`イベントだけでは、アプリが非アクティブの場合にSpaceキーを取得できない。

そのため、Spaceキーについては**グローバルキーボード監視**を使用する。

実装候補：

```text
Windows Low-Level Keyboard Hook
WH_KEYBOARD_LL
```

これにより、アプリがバックグラウンドに存在していてもSpaceキーを検知できるようにする。

### 15.1 他アプリへの影響

Spaceキーを検知しても、Spaceキー入力そのものを他アプリから奪わない。

想定動作：

```text
ユーザーがSpaceを押す
       ↓
Color Spotter
「Spaceが押された」と認識
       ↓
色を固定 / 解除
       ↓
Spaceキー自体は通常通り他アプリへ渡す
```

これにより、他アプリケーションでSpaceキーを使用する操作への影響を最小限にする。

## 16. 色データモデル

アプリ内部では、取得した色を以下のデータとして管理する。

```text
ColorData

RGB
 ├─ R : 0～255
 ├─ G : 0～255
 └─ B : 0～255

HSV
 ├─ H : 0～360
 ├─ S : 0～100
 └─ V : 0～100
```

将来的な拡張を考慮し、RGB/HSV変換処理はUIから分離する。

## 17. 推奨クラス構成

```text
SupoTarou
│
├─ MainWindow
│
├─ Controls
│   ├─ HueRingControl
│   └─ SVBoxControl
│
├─ Services
│   ├─ ScreenColorSampler
│   └─ ColorConverter
│
├─ Input
│   └─ GlobalKeyboardHook
│
└─ Models
    └─ ColorData
```

### MainWindow

UI全体を管理する。

### ScreenColorSampler

マウスカーソル位置の画面色を取得する。

### ColorConverter

RGB⇔HSVなどの色変換を担当する。

### HueRingControl

Hリングの描画とHマーカーの表示を担当する。

### SVBoxControl

SV四角形とS/Vマーカーの描画を担当する。

### GlobalKeyboardHook

アプリが非アクティブでもSpaceキーを検出する。

## 18. 状態管理

アプリには最低限、以下の2状態を持たせる。

```csharp
enum PickerState
{
    Sampling,
    Locked
}
```

### Sampling

カーソル位置の色をリアルタイム取得する。

### Locked

固定した色を表示し、カーソル移動では色を変更しない。

状態遷移：

```text
             Space
   ┌────────────────────┐
   │                    ↓
Sampling ───────────→ Locked
   ↑                    │
   └────────────────────┘
             Space
```

## 19. 非機能要件

### 19.1 応答性

マウスを動かした際に、色表示の更新がユーザーに遅延を感じさせないこと。

目標：

**色取得からUI反映まで100ms未満**を目安とする。

### 19.2 CPU使用率

色取得中でも過剰なCPU使用率にならないこと。

特に、画面全体を毎フレームキャプチャするような実装は避ける。

### 19.3 メモリ

通常利用時に不要な画像データを蓄積しない。

長時間動作によるメモリ増加が発生しないこと。

---

## 20. マルチモニター

Windowsの複数ディスプレイ環境に対応する。

カーソルがどのモニター上にあっても、その位置の色を取得する。

---

## 21. DPI対応

Windowsのディスプレイ倍率が、

```text
100%
125%
150%
200%
```

などに設定されている環境でも、カーソル位置と取得する画面ピクセルの座標が正しく対応すること。

特に以下を考慮する。

- マルチモニター
- 異なるDPIのモニター
- 4Kディスプレイ

**Per-Monitor DPI対応を前提とする。**

---

## 22. エラー・例外処理

画面色を取得できなかった場合でも、アプリがクラッシュしないこと。

例えば、

```text
画面取得失敗
      ↓
直前の色を維持
```

などの安全な処理を行う。

## 25. 受け入れ条件

### AC-01 色取得

マウスカーソルを画面上の色の異なる場所へ移動すると、表示されるHSV値が変化する。

### AC-02 Hリング

取得したHSVのHに対応する位置がHリング上に表示される。

### AC-03 Hリングの基準位置

H=60°（黄色）がHリングの真上に表示される。

### AC-04 SV四角形

取得したHSVのS/Vに対応する位置がSV四角形上に表示される。

### AC-05 数値との一致

表示されるHSV数値と、Hリング/SV四角形上のマーカー位置が一致する。

### AC-06 非アクティブ

別のアプリをアクティブにした状態でも、マウスカーソル位置の色を取得できる。

### AC-07 Space固定

取得中にSpaceキーを押すと、その時点の色が固定される。

### AC-08 固定中

固定中にマウスを移動しても、表示色が変化しない。

### AC-09 Space解除

固定中にSpaceキーを押すと固定が解除され、現在のカーソル位置の色の取得が再開される。

### AC-10 非アクティブSpace

別のアプリがアクティブな状態でもSpaceキーによる固定・解除ができる。

### AC-11 Spaceキーの副作用

Color SpotterがSpaceキーを検知しても、可能な限り他アプリケーションのSpaceキー操作を妨げない。

### AC-12 マルチモニター

複数モニター環境で、どのモニター上にカーソルがあっても正しい色を取得できる。

### AC-13 DPI

Windowsのディスプレイ倍率を変更した環境でも、カーソル位置と取得ピクセルが一致する。
